# React Color Moves Board

A simple React project to practice **useState with objects** and **props**.

## Features
- Independent move counter for Blue, Yellow, Green, and Red
- State managed using a single object
- Button click updates UI instantly
- Clean and beginner-friendly UI

## Concepts Used
- React `useState`
- State as an Object
- Event Handling
- Props

## Purpose
This project was built to strengthen React fundamentals and understand
how state and props work together.

## How to Run
1. Clone the repo
2. Run `npm install`
3. Run `npm run dev` or `npm start`
